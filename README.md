# steam-frame-extras
Small tools for the steam frame I've made for myself that I've found helpful. These may become unneccesary in the future via updates from Valve etc.

frame-mover.sh - Automatically move games to a virtual monitor after a delay. I found running a game through wayland (not Xwayland, so one would be using GE-Proton here) that the screen would be very messed up if you even got the game to display, it'd mostly show a loading screen. 
creating a virtual screen fixed that, but I'd have to move the display over. This does it automatically.
